Optar Browser Edition — How-To Guide

What is Optar?

Optar (OPTical ARchiver) encodes any file as a pattern of dots on paper. Print the pattern with a laser printer. To recover the file later, scan the paper and decode. Each A4/Letter page holds approximately 200 KB. Error correction (BCH(63,45,t=3) code) makes it resilient to paper folding, dust, and minor damage.

Encoding (File → Paper)

  1. Open optar.html in your browser. No internet connection required.
  2. Select the Encode tab.
  3. Click Choose File and select any file you want to archive.
  4. Optionally adjust Settings (paper size, grid density). Defaults work for most 600 DPI laser printers.
  5. Click Encode. The application generates one or more page images.
  6. For each page, click Print or Download PNG. Use a laser printer at 600 DPI or higher; inkjet bleeds reduce reliability.
  7. Note the format string (e.g. 0-65-93-24-3-10-2-24) printed at the bottom of every page. You will need it for decoding.

Important: Files are zero-padded to fill the last page. If your file format is sensitive to trailing zeros, wrap it in a tar or zip archive first.

Decoding (Paper → File)

  1. Scan your pages at 600 DPI grayscale. Format: PNG, color mode grayscale, gamma off.
  2. Name files so they sort in page order, e.g. scan_0001.png, scan_0002.png.
  3. Open the Decode tab.
  4. Click Choose Files and select all your scan images.
  5. Type the format string from the bottom of any page (e.g. 0-65-93-24-3-10-2-24).
  6. Click Decode. Per-page BCH error statistics are displayed:
    • 0 errors: perfect readout (most codewords should land here)
    • 1–3 errors: corrected automatically
    • Uncorrectable: data damage detected; those 12-bit symbols are unreliable
  7. Click Download decoded file.

Troubleshooting

ProblemSolution
High uncorrectable error countRe-scan at higher DPI; clean scanner glass; press paper flatter.
Decoder can't find cornersEnsure the entire page including borders is within the scan area.
Pages out of orderRename files to sort correctly; check page sequence numbers.
File has trailing garbageThe original file was zero-padded; strip trailing zeros or unwrap from tar/zip.
Blank outputCheck that you entered the correct format string.
